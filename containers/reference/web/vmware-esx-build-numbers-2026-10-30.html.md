- VMware vSphere ESX 9.1.x
- VMware vSphere ESXi
- VMware ESX 4.x

The tables below list the ESXi build numbers and versions in order of their release dates.

**Notes:**
- For download information, refer to VMware vSphere downloads, VMware Converter, OEM custom images, patches and addons in the Broadcom Support Portal
- VMware vSAN is integrated into ESXi at the kernel layer and vSAN releases have been bound with ESXi release for several years - Build numbers of ESXi may be used to see the latest release of ESXi, which includes vSAN.
