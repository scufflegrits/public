# Claude Code Multi-Agent & Workflow Guide

**A Practical Introduction for System Engineers**

This guide explains how to use Claude Code’s multi-agent and workflow features. It is written for system engineers who are new to Claude Code.

## How to use this guide

- Read sequentially if you are new to Claude Code.
- Jump to specific sections if you already know the basics.
- Diagrams are inline Mermaid and render on GitHub.
